MODEL VERSION: DIRECT-LINK + EXPLAINABLE DEAL SIGNALS

WHY WE REVISED THE MODEL:
=========================

Affiliate onboarding portals are not reliably accessible in your environment.
The project must work without depending on affiliate registration links.

NEW CORE MODEL:
===============

1. DIRECT-LINK FIRST (NO BLOCKER DEPENDENCY)
   - Recommendations return direct store URL from tracked prices.
   - Users can still click and buy immediately.
   - Affiliate tags are optional and can be added later.

2. EXPLAINABLE DEAL-SIGNAL ENGINE
   - Real/fake discount detection is done by deterministic rules.
   - No opaque black-box scoring required.
   - Output labels:
     - GENUINE_BARGAIN
     - FAKE_DISCOUNT
     - NORMAL
     - INSUFFICIENT_DATA

3. AI IS OPTIONAL, NOT REQUIRED
   - LLM remains supported, but the system works without it.
   - Cohere model is now configurable via env variable.
   - Core recommendation path uses historical price logic.

================================================================================

TECHNICAL RULES (DEAL CLASSIFIER):
==================================

Rule A: GENUINE_BARGAIN
IF current_price < (0.9 * average_30_day_price)
AND current_price <= min_30_day_price
THEN label = GENUINE_BARGAIN

Rule B: FAKE_DISCOUNT
IF current_price < (0.9 * previous_day_price)
AND previous_day_price > (1.2 * average_30_day_price)
THEN label = FAKE_DISCOUNT

Else:
label = NORMAL

WHAT CHANGED IN BACKEND:
========================

1. Added deal signal engine:
   - File: agents/deal_signal.py
   - Functions:
     - evaluate_deal_signal(...)
     - evaluate_from_history(...)

2. Updated price tracking logic:
   - File: agents/price_tracker.py
   - get_price_history now returns:
     - deal_signal
     - deal_score
   - should_buy_now now factors fake-discount/genuine-bargain logic.

3. Added direct buy URL in recommendations:
   - File: agents/recommendation_engine.py
   - Recommendation items now include buy_url.
   - URL is selected from lowest in-stock product_prices row.

4. Added new API endpoint:
   - File: api.py
   - GET /api/price-tracker/deal-signal
   - Returns deal label, score, recommendation, and key metrics.

5. Model configuration is now flexible:
   - File: agents/ai_predictor.py
   - COHERE_MODEL_NAME from env replaces hardcoded model.

6. Dependencies:
   - Added cloudscraper to requirements.txt

4. Check endpoints:
